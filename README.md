## 🚀 Key Features

### 1. Full-Screen AI Dashboard
A gorgeous, glassmorphic UI that adapts perfectly to your VS Code Light/Dark themes. Manage your models, view context, and chat with AI in a spacious environment.

### 2. Intelligent Fill-in-the-Middle (FIM) Autocomplete
As you type, Chanakya AI predicts your next lines of code and provides ghost-text suggestions. Just press `Tab` to accept!

### 3. Context-Aware Chat
Highlight any code in your editor and send it directly to Chanakya. Ask it to explain, refactor, or find bugs within the specific context you provided.

### 4. Custom Model Hub
Easily switch between different LLMs (e.g., Qwen 27B, GPT-4o, Llama 3) via the built-in configuration dashboard. Supports custom headers for enterprise environments.

## ⌨️ Keyboard Shortcuts & Commands

Maximize your productivity with these built-in shortcuts:

| Shortcut (Mac) | Shortcut (Windows/Linux) | Action |
| :--- | :--- | :--- |
| **`Cmd + Alt + I`** | **`Ctrl + Alt + I`** | **Open AI Dashboard**: Opens the full-screen Chanakya AI interface. |
| **`Cmd + Alt + L`** | **`Ctrl + Alt + L`** | **Add to Context**: Sends the currently selected code to the Chanakya Chat. |

### Available Command Palette Actions (`Cmd+Shift+P`):
- `Chanakya AI Enhancer: Open AI Dashboard` - Launch the main UI.
- `Chanakya AI Enhancer: Add Selection to Chat` - Send code to AI.
- `Chanakya AI Enhancer: Configure API Key / Model Endpoint` - Securely update API keys in OS Keychain.
- `Chanakya AI Enhancer: Clear Chat History` - Wipe current conversation.
- `Chanakya AI Enhancer: Trigger Inline Autocomplete` - Manually force a FIM suggestion.
